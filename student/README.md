# 🕌 LiveKit Islamic Classroom

Full-featured Islamic online classroom with LiveKit + Supabase.

## Files
- livekit-class.html — Main app (17 parts)
- sw.js — Service Worker
- manifest.json — PWA manifest
- icons/ — 72, 96, 128, 192, 512 PNGs
- TESTING.md — Testing checklist
- DEPLOY.md — Deployment guide

## Features
- LiveKit WebRTC video/audio
- Chat + file upload
- Hand raise queue
- Whiteboard
- Poll + Quiz
- Recording + Cloud upload
- Live transcription
- Chat translation
- AI summary
- Session replay
- Content library
- Breakout rooms
- Attendance viewer
- Islamic tools (Quran, Tasbih, Prayer, Qibla, Hadith, Tafsir)
- PWA + Offline + Push
- Accessibility (A11y)

## Keyboard Shortcuts
- M — Mic toggle
- V — Camera toggle
- S — Screen share
- C — Chat
- P — Participants
- H — Hand raise
- W — Whiteboard
- R — Record
- Esc — Close

## Quick Start
1. Deploy Supabase functions
2. Set env vars
3. Update SUPABASE_URL in HTML
4. Create DB tables
5. Open livekit-class.html?room=test&teacher=true
